# Task Management Backend API

Node.js & Express backend for managing tasks using Prisma ORM and PostgreSQL (Neon).

## Features
- Task management (POST /tasks, GET /tasks, GET /tasks?status=Pending, GET /tasks/:id)
- Authorization middleware for POST requests
- Input validation and status code management
